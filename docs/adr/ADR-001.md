## Verification contract

Map unit behavior, affected integration boundaries, promised contracts, static checks, build, health, smoke, and user journeys to the stack's native tools. Node's `node:test` / `node:assert/strict` are one JS/TS option, not a requirement for every stack. Native test layouts are valid.

Required checks must execute meaningful cases and report failures. A zero-test run cannot satisfy a behavioral check. A not-applicable check requires a reason and independent reviewer acceptance. Tests already covering a change can be reused; add tests for meaningful new behavior or regressions. Define flaky-test handling and any approved exception with an owner and expiry.

The platform owner establishes the real CI gates in the bootstrap ticket. Record commands, SHA, outcomes/counts, and relevant artifacts using `templates/tasks/evidence.md`. Templates do not establish application readiness by themselves.
