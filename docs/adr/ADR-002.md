# ADR-002 — Hybrid dispatcher + /goal

Status: DRAFT — adopt or drop per project. LIMITED trial: only after the first ticket has been integrated in core with the orchestrator driving directly.

## Design

- Dispatcher = ONE Codex pane in core, holding `/goal` per ticket (acceptance + hard stop clause).
- Dispatch + collect only. No architecture decisions, no register writes, no writable worktree (reads only the integration branch / `main`).
- Everything escalates to the orchestrator. Kill-switch: the orchestrator takes over direct driving.
- The architect never holds `/goal`.
